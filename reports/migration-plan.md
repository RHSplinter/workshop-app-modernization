# Migration Plan — PartsCatalogAPI: .NET Framework 4.8 → .NET 10

**Plan Date:** April 15, 2026  
**Source:** `src/PartsCatalogAPI` (.NET Framework 4.8, ASP.NET Web API 2, EF6)  
**Target:** .NET 10, ASP.NET Core, EF Core 10  
**Security Audit:** `reports/security-audit.md`

---

## Overview

The migration consists of seven phases. Phases 1 and 2 address security vulnerabilities that must be resolved before or during the framework transition. Phases 3–5 cover the technical migration work. Phase 6 validates the result. Phase 7 covers post-migration hardening.

| Phase | Name | When |
|-------|------|------|
| 1 | Pre-Migration Security Fixes | Before migration |
| 2 | Project Infrastructure | Start of migration |
| 3 | Startup & Configuration | Migration |
| 4 | Data Layer | Migration |
| 5 | Controllers | Migration |
| 6 | Security Hardening | During migration |
| 7 | Validation | After migration |
| 8 | Post-Migration Hardening | After migration |

## Phase 1 — Pre-Migration Security Fixes

These issues are exploitable in the current .NET Framework application and must be remediated before touching the framework itself.

### 1.1 Remove the Debug Endpoint [CRITICAL-4]

**File:** `Controllers/ProductsController.cs`, lines 155–167

Delete the `GetDebugInfo()` action entirely. It returns `AdminUsername`, `ApiKey`, database server, and database name to any unauthenticated caller.

```csharp
// DELETE this entire method
[HttpGet]
[Route("api/Products/Debug")]
public IHttpActionResult GetDebugInfo() { ... }
```

### 1.2 Remove Hardcoded Credentials from Web.config [CRITICAL-3]

**File:** `Web.config`, lines 5–9 and 12

- Remove `AdminUsername`, `AdminPassword`, `ApiKey`, and `EnableDebugMode` from `<appSettings>`.
- Replace the SA-account connection string with a least-privilege login (see 1.4).
- Treat the `ApiKey` value `12345-ABCDE-67890-FGHIJ` as compromised — rotate it immediately.

These values should come from environment variables in development and Azure Key Vault in production (implemented in Phase 3).

### 1.3 Disable Debug Mode and Fix Error Disclosure [HIGH-2]

**File:** `Web.config`, lines 17–18

```xml
<!-- Before -->
<compilation debug="true" targetFramework="4.8" />
<customErrors mode="Off" />

<!-- After -->
<compilation debug="false" targetFramework="4.8" />
<customErrors mode="RemoteOnly" />
```

### 1.4 Replace SA Account with Least-Privilege Login [HIGH-3]

Create a dedicated SQL login with only the permissions the application requires:

```sql
CREATE LOGIN PartsCatalogApp WITH PASSWORD = '<strong-generated-password>';
CREATE USER PartsCatalogApp FOR LOGIN PartsCatalogApp;
GRANT SELECT, INSERT, UPDATE, DELETE ON SCHEMA::dbo TO PartsCatalogApp;
```

Update `Web.config` to use this login instead of `sa`. Store the new password in an environment variable, not in source control.

### 1.5 Remove DropCreateDatabaseIfModelChanges Initializer [HIGH-4]

**File:** `Data/PartsCatalogInitializer.cs`, line 9

The `DropCreateDatabaseIfModelChanges<T>` initializer will silently drop the production database if the EF model changes. Remove or replace with a no-op before any further schema changes:

```csharp
// Remove this class entirely, or replace with:
public class PartsCatalogInitializer : NullDatabaseInitializer<PartsCatalogContext> { }
```

Database seeding will be moved to idempotent `HasData()` calls in Phase 4.

### 2.2 Delete Framework-Specific Files

The following files have no equivalent in ASP.NET Core and must be removed:

| File | Replacement |
|------|-------------|
| `Global.asax` / `Global.asax.cs` | `Program.cs` |
| `App_Start/WebApiConfig.cs` | Inline in `Program.cs` |
| `Web.config` | `appsettings.json` / `appsettings.{Environment}.json` |
| `Web.Debug.config` | `appsettings.Development.json` |
| `Web.Release.config` | `appsettings.Production.json` |
| `packages.config` | `<PackageReference>` in `.csproj` |
| `Properties/AssemblyInfo.cs` | Auto-generated by SDK |

### 2.3 Replace Newtonsoft.Json [HIGH-5 — CVE-2024-21907]

Newtonsoft.Json 9.0.1 (current) is vulnerable to a DoS stack overflow. ASP.NET Core uses `System.Text.Json` by default — no additional package is needed. Do not add a `Newtonsoft.Json` reference in the migrated project.

If Entity Framework tooling and runtime versions drift, update the global EF tool:

```bash
dotnet tool update --global dotnet-ef
```

## Phase 3 — Startup & Configuration

### 3.1 Create Program.cs

```csharp
using Microsoft.EntityFrameworkCore;
using PartsCatalogAPI.Data;

var builder = WebApplication.CreateBuilder(args);

// Configuration — no secrets in appsettings.json
builder.Configuration.AddEnvironmentVariables();
// Uncomment for Azure Key Vault:
// builder.Configuration.AddAzureKeyVault(new Uri(builder.Configuration["KeyVaultUri"]!), new DefaultAzureCredential());

// Services
builder.Services.AddControllers()
    .AddJsonOptions(options =>
    {
        options.JsonSerializerOptions.PropertyNamingPolicy = JsonNamingPolicy.CamelCase;
        options.JsonSerializerOptions.ReferenceHandler = ReferenceHandler.IgnoreCycles;
    });

var connectionString = builder.Configuration.GetConnectionString("DefaultConnection");
if (string.IsNullOrWhiteSpace(connectionString))
{
    throw new InvalidOperationException("Connection string 'DefaultConnection' is not configured.");
}

builder.Services.AddDbContext<PartsCatalogContext>(options =>
    options.UseSqlServer(connectionString, sqlOptions =>
    {
        sqlOptions.EnableRetryOnFailure(5, TimeSpan.FromSeconds(10), null);
    }));

builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options => { /* configure */ });

builder.Services.AddAuthorization(options =>
{
    options.FallbackPolicy = new AuthorizationPolicyBuilder()
        .RequireAuthenticatedUser()
        .Build();
});

builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowTrustedOrigins", policy =>
    {
        var origins = builder.Configuration.GetSection("AllowedOrigins").Get<string[]>() ?? Array.Empty<string>();

        if (origins.Length > 0)
        {
            policy.WithOrigins(origins)
                .WithMethods("GET", "POST", "PUT", "DELETE")
                .AllowAnyHeader()
                .AllowCredentials();
        }
    });
});

var app = builder.Build();

// Apply pending EF Core migrations at startup
await using (var scope = app.Services.CreateAsyncScope())
{
    var db = scope.ServiceProvider.GetRequiredService<PartsCatalogContext>();
    await db.Database.MigrateAsync();
}

// Middleware
if (!app.Environment.IsDevelopment())
{
    app.UseExceptionHandler("/error");
    app.UseHsts();

    var httpsPort = builder.Configuration.GetValue<int?>("HTTPS_PORT")
        ?? builder.Configuration.GetValue<int?>("ASPNETCORE_HTTPS_PORT");

    if (httpsPort.HasValue)
    {
        app.UseHttpsRedirection();
    }
}

// Security headers [MEDIUM-3]
app.Use(async (context, next) =>
{
    context.Response.Headers.Append("X-Content-Type-Options", "nosniff");
    context.Response.Headers.Append("X-Frame-Options", "DENY");
    context.Response.Headers.Append("Referrer-Policy", "strict-origin-when-cross-origin");
    await next();
});

app.UseCors("AllowTrustedOrigins");
app.UseAuthentication();
app.UseAuthorization();

app.MapGet("/", () => Results.Ok(new { service = "PartsCatalogAPI", status = "ok" })).AllowAnonymous();
app.MapGet("/health", () => Results.Ok(new { status = "healthy" })).AllowAnonymous();

app.MapControllers();
app.Run();
```

## Phase 4 — Data Layer

### 4.1 Migrate PartsCatalogContext to EF Core

**Key API changes:**

| EF6 | EF Core |
|-----|---------|
| `: DbContext("name=DefaultConnection")` | Constructor receives `DbContextOptions<T>` |
| `DbModelBuilder` | `ModelBuilder` |
| `HasRequired().WithMany()` | `HasOne().WithMany()` |
| `WillCascadeOnDelete(false)` | `OnDelete(DeleteBehavior.Restrict)` |
| `.Include("Category")` string | `.Include(p => p.Category)` lambda |

```csharp
public class PartsCatalogContext : DbContext
{
    public PartsCatalogContext(DbContextOptions<PartsCatalogContext> options)
        : base(options) { }

    public DbSet<Product> Products => Set<Product>();
    public DbSet<Category> Categories => Set<Category>();

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<Product>()
            .Property(p => p.Price)
            .HasPrecision(18, 2);

        modelBuilder.Entity<Product>()
            .HasOne(p => p.Category)
            .WithMany(c => c.Products)
            .HasForeignKey(p => p.CategoryId)
            .OnDelete(DeleteBehavior.Restrict);
    }
}
```

### 4.2 Update Models [MEDIUM-5, LOW-2]

**Product.cs and Category.cs changes:**

- Add `[RegularExpression]` validation to `ImageUrl` to block `javascript:` and `data:` URIs (MEDIUM-5).
- Enable nullable reference types — mark optional navigation properties as nullable.
- In verbatim string literals (`@"..."`), escape `"` as `""` inside the regex character class.

```csharp
[StringLength(500)]
[RegularExpression(@"^https?://[^\s<>""]+$", ErrorMessage = "ImageUrl must be a valid http/https URL")]
public string? ImageUrl { get; set; }
```

### 4.3 Delete PartsCatalogInitializer

Remove `Data/PartsCatalogInitializer.cs` entirely (completed in Phase 1). Seed data moves to `OnModelCreating` using `HasData()`.

### 4.4 Create Initial EF Core Migration

EF Core migrations are incompatible with EF6 migrations. Apply all EF6 migrations to the database first to reach the current schema, then scaffold a baseline EF Core migration:

```bash
dotnet ef migrations add InitialCreate
# Manually empty the Up() and Down() methods to mark the baseline
# (the schema already exists in the database)
dotnet ef database update
```

Future schema changes will use normal `dotnet ef migrations add <Name>`.

## Phase 5 — Controllers

### 5.1 Migration Map

| Aspect | Before | After |
|--------|--------|-------|
| Base class | `ApiController` | `ControllerBase` |
| Namespace | `System.Web.Http` | `Microsoft.AspNetCore.Mvc` |
| Return type | `IHttpActionResult` | `ActionResult<T>` |
| Routing | Convention in `WebApiConfig` | `[Route("api/[controller]")]` attribute |
| DI | Field initializer `= new Context()` | Constructor injection |

| Configuration | `ConfigurationManager` | `IConfiguration` via DI |
| Authorization | None | `[Authorize]` / `[AllowAnonymous]` |

### 5.2 ProductsController

**Changes required:**

- `[CRITICAL-1]` Replace `SearchProducts` raw SQL with EF Core LINQ.
- `[CRITICAL-4]` Delete `GetDebugInfo()` (already done in Phase 1; confirm absent).
- `[HIGH-1]` Add `[Authorize]` at class level; add `[AllowAnonymous]` on read-only GET endpoints.
- `[LOW-1]` Replace field initializer with constructor injection.
- `[LOW-2]` Replace `DateTime.Now` with `DateTime.UtcNow` on lines 78 and 115.
- Make all methods async.

```csharp
[ApiController]
[Route("api/[controller]")]
[Authorize]
public class ProductsController : ControllerBase
{
    private readonly PartsCatalogContext _context;

    public ProductsController(PartsCatalogContext context) => _context = context;

    [HttpGet]
    [AllowAnonymous]
    public async Task<ActionResult<IEnumerable<Product>>> GetProducts()
        => await _context.Products.Include(p => p.Category).ToListAsync();

    [HttpGet("{id}")]
    [AllowAnonymous]
    public async Task<ActionResult<Product>> GetProduct(int id)
    {
        var product = await _context.Products.FindAsync(id);
        return product is null ? NotFound() : product;
    }

    // CRITICAL-1 fixed: EF Core LINQ, no raw SQL
    [HttpGet("search")]
    [AllowAnonymous]
    public async Task<ActionResult<IEnumerable<Product>>> SearchProducts([FromQuery] string name)
    {
        if (string.IsNullOrWhiteSpace(name))
            return BadRequest("name is required");

        return await _context.Products
            .Include(p => p.Category)
            .Where(p => p.Name.Contains(name))
            .ToListAsync();
    }

    [HttpPost]
    public async Task<ActionResult<Product>> PostProduct(Product product)
    {
        product.CreatedDate = DateTime.UtcNow;  // LOW-2
        product.IsActive = true;
        _context.Products.Add(product);
        await _context.SaveChangesAsync();
        return CreatedAtAction(nameof(GetProduct), new { id = product.Id }, product);
    }

    [HttpPut("{id}")]
    public async Task<IActionResult> PutProduct(int id, Product product)
    {
        if (id != product.Id) return BadRequest();
        var existing = await _context.Products.FindAsync(id);
        if (existing is null) return NotFound();

        existing.Name = product.Name;
        existing.Description = product.Description;
        existing.Price = product.Price;
        existing.StockQuantity = product.StockQuantity;
        existing.Sku = product.Sku;
        existing.CategoryId = product.CategoryId;
        existing.ImageUrl = product.ImageUrl;
        existing.LastModifiedDate = DateTime.UtcNow;  // LOW-2
        existing.IsActive = product.IsActive;

        await _context.SaveChangesAsync();
        return Ok(existing);
    }

    [HttpDelete("{id}")]
    [Authorize(Roles = "Admin")]
    public async Task<IActionResult> DeleteProduct(int id)
    {
        var product = await _context.Products.FindAsync(id);
        if (product is null) return NotFound();
        _context.Products.Remove(product);
        await _context.SaveChangesAsync();
        return Ok(product);
    }

    [HttpGet("low-stock")]
    [AllowAnonymous]
    public async Task<ActionResult<IEnumerable<Product>>> GetLowStockProducts()
        => await _context.Products.Where(p => p.StockQuantity < 10).ToListAsync();
}
```

### 5.3 CategoriesController

**Changes required:**

- `[CRITICAL-2]` Replace `GetCategoryByName` raw SQL with EF Core LINQ.
- `[HIGH-1]` Add `[Authorize]` at class level; `[AllowAnonymous]` on read-only endpoints.
- `[LOW-1]` Replace field initializer with constructor injection.
- Make all methods async.

```csharp
[ApiController]
[Route("api/[controller]")]
[Authorize]
public class CategoriesController : ControllerBase
{
    private readonly PartsCatalogContext _context;

    public CategoriesController(PartsCatalogContext context) => _context = context;

    [HttpGet]
    [AllowAnonymous]
    public async Task<ActionResult<IEnumerable<Category>>> GetCategories()
        => await _context.Categories.ToListAsync();

    [HttpGet("{id}")]
    [AllowAnonymous]
    public async Task<ActionResult<Category>> GetCategory(int id)
    {
        var category = await _context.Categories.FindAsync(id);
        return category is null ? NotFound() : category;
    }

    // CRITICAL-2 fixed: EF Core LINQ, no raw SQL
    [HttpGet("by-name")]
    [AllowAnonymous]
    public async Task<ActionResult<Category>> GetCategoryByName([FromQuery] string name)
    {
        if (string.IsNullOrWhiteSpace(name))
            return BadRequest("name is required");

        var category = await _context.Categories
            .FirstOrDefaultAsync(c => c.Name == name);

        return category is null ? NotFound() : category;
    }

    [HttpGet("{id}/products")]
    [AllowAnonymous]
    public async Task<ActionResult<IEnumerable<Product>>> GetCategoryProducts(int id)
    {
        if (!await _context.Categories.AnyAsync(c => c.Id == id))
            return NotFound();

        return await _context.Products.Where(p => p.CategoryId == id).ToListAsync();
    }

    [HttpPost]
    public async Task<ActionResult<Category>> PostCategory(Category category)
    {
        category.IsActive = true;
        _context.Categories.Add(category);
        await _context.SaveChangesAsync();
        return CreatedAtAction(nameof(GetCategory), new { id = category.Id }, category);
    }
}
```

## Phase 7 — Validation

Run these checks after the migration is complete but before promoting to staging.

```bash
# Build
dotnet build src/PartsCatalogAPI/PartsCatalogAPI.csproj

# Test
dotnet test src/PartsCatalogAPI/PartsCatalogAPI.csproj

# Apply EF Core migrations
dotnet ef database update --project src/PartsCatalogAPI --startup-project src/PartsCatalogAPI

# Run the application
dotnet run --project src/PartsCatalogAPI
```

**Endpoint verification checklist:**

- [ ] `GET /api/products` — returns list, no auth required
- [ ] `GET /api/products/{id}` — returns single product (or 404 when no seeded data exists)
- [ ] `GET /api/products/search?name=brake` — returns filtered results; SQL injection test (`'; DROP TABLE Products;--`) returns 400 or empty results safely
- [ ] `GET /api/products/low-stock` — returns low-stock items
- [ ] `GET /api/products/debug` — returns **404** (or **401** when fallback authorization challenges unmatched routes)
- [ ] `POST /api/products` — requires valid JWT; returns 201 on success
- [ ] `PUT /api/products/{id}` — requires valid JWT; returns 200
- [ ] `DELETE /api/products/{id}` — requires Admin role JWT; returns 200
- [ ] `GET /api/categories` — returns list
- [ ] `GET /api/categories/by-name?name=Brakes` — returns category (or 404 when no seeded data exists); SQL injection test safe
- [ ] `GET /api/categories/{id}/products` — returns products for category (or 404 when category does not exist)
- [ ] Response headers include `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`
- [ ] No secrets appear in any HTTP response body

### 7.1 Runtime Troubleshooting

- If startup fails with `Invalid object name 'Products'`, create and apply the initial EF migration:

```bash
dotnet ef migrations add InitialCreate --project src/PartsCatalogAPI --startup-project src/PartsCatalogAPI
dotnet ef database update --project src/PartsCatalogAPI --startup-project src/PartsCatalogAPI
```

- If startup warns `Failed to determine the https port for redirect`, configure `ASPNETCORE_HTTPS_PORT` or conditionally enable HTTPS redirection only when a port is configured.

## Phase 8 — Post-Migration Hardening

Recommended after the .NET 10 baseline is stable in staging.

- **Rate limiting** — `app.UseRateLimiter()` with per-IP fixed window policy on write endpoints
- **OpenTelemetry** — Instrument all database calls and HTTP requests for distributed tracing
- **Structured logging** — Add Serilog with console and Application Insights sinks; ensure no sensitive data is logged
- **Integration tests** — Cover authorization boundaries (unauthenticated → 401, wrong role → 403)
- **Azure Defender for SQL** — Enable continuous vulnerability assessment on the database
- **Dependabot / Renovate** — Automated PR alerts for package CVEs
